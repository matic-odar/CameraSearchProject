# Search Tracker

Android app (Expo / React Native, TypeScript) for systematically searching an area on foot:
it records where you have walked as a line whose width is in **real meters**, so you can see
what is covered and what is not. Map = Leaflet inside a WebView (OpenStreetMap or Esri satellite, no API keys).

## Files
| File | What |
|---|---|
| `App.tsx` | All UI: map WebView, status, bottom bar, draw toolbar, settings modal |
| `src/tracking.ts` | Background location task (expo-task-manager + foreground service), filtering, start/stop |
| `src/storage.ts` | Persistence (expo-file-system), geo math, GPX/GeoJSON export |
| `src/mapHtml.ts` | Leaflet page: meter-width track, areas, draw mode, blue dot |
| `src/leafletAssets.ts` | Leaflet 1.9.4 inlined (generated by `scripts/gen-leaflet.js`) |

Data lives in the app's document directory: `track.ndjson` (append-only, one point per line),
`sessions/*.ndjson` (archived sessions), `areas.json`, `settings.json`, `meta.json`.

## Build an installable APK

Background location needs a real build (not Expo Go).

### Option A — EAS cloud build (from your computer)
```bash
# from the repo root
npm install
npx eas-cli@latest login
npx eas-cli@latest init          # first time only: links/creates the Expo project (adds projectId to app.json)
npx eas-cli@latest build -p android --profile preview
```
When it finishes, EAS prints a link/QR code to the `.apk`.

### Option B — GitHub Actions
`.github/workflows/build-apk.yml` runs on every push to `main`
(or manually: Actions → *Search Tracker APK* → *Run workflow*).
- If the repo secret `EXPO_TOKEN` is set (expo.dev → Account settings → Access tokens), it runs
  `eas build --local --profile preview` on the runner.
- Without the secret it falls back to `expo prebuild` + `gradlew assembleRelease`.

Download the APK from the run page → **Artifacts → search-tracker-apk** (a zip containing `search-tracker.apk`).

### Install on the phone
1. Copy `search-tracker.apk` to the phone (or open the EAS link on the phone).
2. Tap it; allow "Install unknown apps" for your browser/file manager when Android asks.
3. Open Search Tracker → Start → allow location **"While using the app"**, then on the next screen choose
   **"Allow all the time"**.
4. Recommended: Settings → Apps → Search Tracker → Battery → **Unrestricted**, and allow notifications.
